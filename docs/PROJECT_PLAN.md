# 8-Week Project Plan

## Week 1
Build baseline RAG and learn tokenization, embeddings, prompting, and grounding.

## Week 2
Replace TF-IDF with embeddings. Add pgvector. Benchmark chunking and retrieval.

## Week 3
Add hybrid retrieval and reranking. Build a retrieval evaluation dataset.

## Week 4
Add LangGraph and tools. Build an investigation workflow with human approval.

## Week 5
Add agent evaluation, LLM-as-judge, traces, token/cost metrics, and feedback.

## Week 6
Add prompt/model versioning and automated regression gates.

## Week 7
Fine-tune a small specialist model with LoRA/QLoRA. Add model routing.

## Week 8
Serve an open-weight model with vLLM. Benchmark quantization, latency, throughput,
and quality. Add prompt-injection and tool-authorization tests.

The goal is not to maximize framework count. The goal is to produce measurable
quality, latency, cost, safety, and reliability results.
